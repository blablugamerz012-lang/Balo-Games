# Balo Games

Welcome to **Balo Games** — a collection of browser-based games.

This project is updated over time, and new games and features may be added in the future. The README is intentionally kept general so the game list does not need to be updated every time a new game is added.

## Project

- Browse and play the games through the website.
- New games and improvements may be added over time.
- Game preview videos are stored in the `videos/` folder. See [`videos/README.md`](videos/README.md) for the video naming and setup instructions.

## Updates

When adding a game, update the website files as needed. You do not need to add every game's name to this README.
